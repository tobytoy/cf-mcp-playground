資料集統計口徑與分析使用須知 (Usage Notes)
  • 涉案人數與死傷總人數關係： 本資料集來源為警政署開放之「傷亡事故逐案微資料 (A1 死亡 / A2 受傷)」，不含僅車損之 A3 事故。因原始微資料僅標註案件層級（A1 或 A2），彙整時將 A1 事故當事人計入死亡、A2 事故當事人計入受傷，故各列中「涉案人數」與「死傷總人數」數值呈 1:1 對應，代表該維度條件下涉及傷亡事故之總人次。
  • 毒駕事故統計涵蓋範圍： 「毒駕事故 (吸食違禁物)」係比對事故主要肇因或個別肇因判定包含吸毒之案件。統計對象包含該起毒駕事故中被列入微資料之全體當事關係人（包含肇事駕駛、同車乘員與被撞波及之其他車輛/被害人）。資料集中若出現少數「未成年」年齡層，多為該起毒駕事故所波及之無辜受害者。
  • 未滿 18 歲無照駕駛判定： 已嚴格限縮為當事者順位第 1 順位（主要主駕駛人本人），且限定為動力汽機車，已排除同乘少年、乘客或路過行人。
  • 行政區解析涵蓋率： 全表 47,946 筆中，47,945 筆（99.998%）已完全校正對齊台灣法定 368 鄉鎮市區標準；僅 1 筆（114 年 3 月彰化縣）因原始報案地點字串不詳標註為「全區/未明」。

去識別化資料篩選與組合邏輯 (Processing Pipeline)

ETL & Data Cleaning

1. 毒駕事故判定邏輯

比對事故微資料之「肇因研判子類別名稱-主要」與「肇因研判子類別名稱-個別」，嚴格比對包含關鍵字 吸食違禁物駕駛 或 吸毒 之當事者個案。

統計對象包含該起毒駕事故中被列入微資料之全體當事者（含主肇事者與受波及之其他關係人/被害者）。

2. 未滿 18 歲無照駕駛事故判定

篩選「當事者年齡 < 18」且「當事者順位 = 1」(主駕駛人)。精確排除行人與非動力慢車，限定為動力汽機車（普通重機、微電車、大客貨車等）。

排除被載乘客與路過未成年行人，鎖定真實無照主駕行為。

3. 兒童死傷判定與「假 0 歲」清洗

原始資料中常將撞擊「路樹、動物、障礙物」或肇逃者預設填為 0。本版本進行關鍵清洗：嚴格排除性別為「無或物」、「動物」之非自然人紀錄，保留真實的 0-6 歲幼童與 7-12 歲學童死傷。

死傷總人數為 A1 死亡 (24h內) 與 A2 受傷（含重輕傷）總合。

4. 縣市與行政區正規化

從「發生地點」精確萃取行政區（如臺北市大安區、南投縣埔里鎮等），若地點字串未完整標註，則以「處理單位名稱警局層」自動補全縣市歸屬，確保全國 22 縣市跨年度統計口徑完全對齊。

補齊歷年「台」與「臺」同義字對應，統一為標準地名。

# 步驟 2: 繪製 2018-2025 歷年重點指標趨勢 (雙 Y 軸折線圖)
import pandas as pd
import matplotlib.pyplot as plt

# 設定中文字型 (依作業系統相容常用中文字體)
plt.rcParams['font.sans-serif'] = ['Microsoft JhengHei', 'PingFang TC', 'sans-serif']
plt.rcParams['axes.unicode_minus'] = False

df = pd.read_csv("https://traffic-safety-opendata.pages.dev/traffic_safety_stats_107_114.csv")
trend = df.groupby(['西元年', '違規/事故類別'])['死傷總人數'].sum().unstack()

fig, ax1 = plt.subplots(figsize=(10, 5.5))

# 左軸：兒童死傷 (萬級數量)
l1 = ax1.plot(trend.index, trend['兒童交通事故死傷(0-12歲)'], marker='o', color='#2563eb', label='兒童死傷 (0-12歲)', linewidth=2.5)
ax1.set_ylabel('兒童死傷人數 (人)', color='#2563eb')

# 右軸：無照駕駛與毒駕 (百/千級數量)
ax2 = ax1.twinx()
l2 = ax2.plot(trend.index, trend['未滿18歲無照駕駛(駕駛人)'], marker='s', color='#d97706', label='未滿18歲無照駕駛', linewidth=2.5)
l3 = ax2.plot(trend.index, trend['毒駕事故(吸食違禁物)'], marker='^', color='#dc2626', label='毒駕事故', linewidth=2.5)
ax2.set_ylabel('無照 / 毒駕 人數 (人)', color='#dc2626')

ax1.legend(l1 + l2 + l3, [l.get_label() for l in l1 + l2 + l3], loc='center left')
plt.title('2018-2025 台灣交通安全重點指標歷年趨勢')
plt.grid(True, linestyle='--', alpha=0.5)
plt.tight_layout()
plt.show()
# 步驟 3: 繪製 2025 (114年) 各縣市未滿 18 歲無照駕駛事故 Top 10 (水平長條圖)
import pandas as pd
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['Microsoft JhengHei', 'PingFang TC', 'sans-serif']
plt.rcParams['axes.unicode_minus'] = False
df = pd.read_csv("https://traffic-safety-opendata.pages.dev/traffic_safety_stats_107_114.csv")

# 篩選 2025 年無照駕駛個案並按縣市加總涉案人數
df_2025 = df[(df['西元年'] == 2025) & (df['違規/事故類別'] == '未滿18歲無照駕駛(駕駛人)')]
top10 = df_2025.groupby('縣市')['涉案人數'].sum().sort_values().tail(10)

plt.figure(figsize=(9, 5.5))
bars = plt.barh(top10.index, top10.values, color='#0284c7')
plt.title('2025年 各縣市未滿 18 歲無照駕駛事故人數 Top 10')
plt.xlabel('涉案人數 (人)')

for bar in bars:
    w = bar.get_width()
    plt.text(w + 3, bar.get_y() + bar.get_height()/2, f'{int(w):,} 人', va='center', fontsize=9)

plt.tight_layout()
plt.show()
# 步驟 4: 使用 Pivot Table 樞紐分析毒駕近年暴增的縣市熱區
import pandas as pd

df = pd.read_csv("https://traffic-safety-opendata.pages.dev/traffic_safety_stats_107_114.csv")

# 交叉分析: 列為縣市、欄為年份
df_drug = df[df['違規/事故類別'] == '毒駕事故(吸食違禁物)']
pivot_drug = df_drug.pivot_table(index='縣市', columns='西元年', values='涉案人數', aggfunc='sum', fill_value=0)

# 按 2025 年涉案人數排序，檢視前 5 大暴增縣市
top5_counties = pivot_drug.sort_values(by=2025, ascending=False).head(5)
print("=== 毒駕近年暴增主要縣市 (近四年) ===")
print(top5_counties[[2022, 2023, 2024, 2025]])
